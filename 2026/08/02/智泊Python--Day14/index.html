智泊Python–Day14

  Day14 是 Python 基础部分的收官——异常处理。先分清两个概念：错误是代码还没运行就报（语法错、缩进错），异常是运行时才炸（除零、下标越界、键不存在）。异常处理的意义是：让程序遇到意外时不崩溃，而是优雅地捕获、提示、或走兜底逻辑。核心语法就是 try-except 家族，外加主动 raise 和 assert。

 

1.异常错误处理

  异常处理的几种组合：

  • try-except：尝试执行 try，出错就进 except，except 里能拿到异常对象 e（含信息和类型）
  • try-except-else：else 在「没有异常」时才执行
  • try-except-finally：finally 无论是否报错都执行（常用来释放资源，比如关文件、断连接）
  • try-except-else-finally：三者齐全

下面先列出 Python 常见的内置异常类型，再用 raise 主动抛异常、assert 做断言（了解）。注意 raise 那行如果直接运行会终止程序——它演示的是「主动报错」的语法。
