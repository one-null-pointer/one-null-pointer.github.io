1.什么是Langchain

  Langchain 是一个用于构建由 LLM 提供支持的代理和应用程序的框架。作用是简化 LLM 应用的开发难度，方便开发者快速地开发复杂的 LLM 应用。

官网：https://www.langchain.com/langchain

  从 Langchain 0.3 到 Langchain 1.0 的优化：

  • 统一 Agent 创建接口 —— create_agent()
  • 中间件系统（Middleware）—— 细粒度流程控制
  • 标准化输出（.content_blocks）—— 无论使用哪家模型，输出统一为结构化内容块
  • 结构化输出原生支持 —— 将结构化输出直接集成到主循环中
  • 基于 LangGraph 的底层架构 —— Agent 实际是 LangGraph 编排的状态图（StateGraph）
  • 包结构精简与迁移路径 —— 移除冗余模块，核心包更加轻量。旧版本功能（LLMChain，ConversationBufferMemory 等）迁移到了 langchain-classic

 

2.LangChain的核心组件

  LangChain 的组件较多，大致上可以分为六大分类：

  • 模型包装器（Model）：与语言模型交互的接口，例如语言模型（Language Models）、提示词模版（Prompt Templates）、输出解析器（Output Parsers）等
  • 数据连接（Data connection）：与特定应用程序的数据进行交互的接口，例如文档加载器、文档切分、文本嵌入、矢量、检索器等
  • 链（Chains）：将组件组合实现端到端应用，链的存在允许我们将多个组件组合在一起，以创建一个单一的、连贯的应用程序
  • 记忆（Memory）：用于链的多次运行之间持久化应用程序状态
  • 代理与工具（Agents）：扩展模型的推理能力，用于复杂的应用的调用序列
  • 中间件（Middleware）：控制与自定义每个步骤的代理执行

  这里需要注意的是 ChatTongyi 是 LangChain 专门为通义千问写的适配器，它内部已经把这些都硬编码好了，所以调用会更加方便，而 MiniMax 官方提供了 OpenAI 兼容协议，它在 LangChain 里没有专门的 ChatMinimax 类，所以只能用 ChatOpenAI 接口规范，并修改 url 和 model。

  目前模型包装器主要包含三部分内容：提示词、模型调用、输出解析。

  在模型调用中，Langchain 目前支持的模型有三大类：

  • 非对话模型（LLM）包装器：也叫文本补全模型，基于 transformer 架构，通过大规模训练数据学习语言规律，只能一问一答，现在已经比较少用，OpenAI 的文本补全类 API 在 2023 年进行了最后一次更新，所以只需要知道即可
  • 对话聊天模型（Chat Model）包装器：主要代表 OpenAI 的 ChatGPT 系列模型。这些模型通常由语言模型支持，但它们的 API 更加结构化，基于 LLM 构建，通过特定优化（如对话历史管理、角色区分）来提升对话连贯性和上下文理解能力，常见的聊天模型包装器为 ChatOpenAI、BaseChatModel 等
  • 文本嵌入模型（Embedding Model）：将文本作为输入并返回词向量，后续 RAG 内容会使用到

5.Langchain的输出解析器

  Output Parser 是 LLM 链里”LLM 吐出来的文本”和”程序真正要用的结构化数据”之间的一层翻译/适配器。为什么需要它？因为 LLM 只认识字符串——你问它”提取姓名和年龄”，它给你一段 姓名：张三，年龄：25 的自然语言。但你的代码要做 if person.age > 18:、要存数据库、要调 API，这些都吃不了裸文本。Output Parser 就是把”文本”可靠地变成 Person(name=”张三”, age=25) 这种对象。目前常见的解析器有：字符串解析器，CSV 解析器，json 解析器，日期解析等，我们也可以通过自定义去构造需要的解析器内容。

5.1 字符串解析器：StrOutputParser
5.2 CSV解析器：CommaSeparatedListOutputParser
5.3 json解析器：JsonOutputParser
5.4 日期时间解析器：DatetimeOutputParser

  这里需要注意，链里加一步清洗（先剥 <think>...</think>，再用正则精确匹配 %Y-%m-%dT%H:%M:%S.%fZ），把纯时间串交给 DatetimeOutputParser。

6.Langchain的链式

  链的作用是将提示词模版、模型包装器和输出解析器串联起来，利用了提示模版格式化输入，将格式化后的字符串传递给了 LLM 模型，并返回了 LLM 的输出。

  本质上就是单向线性的链表。

  使得整个处理过程更加高效与便捷。
