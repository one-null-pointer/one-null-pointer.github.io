智泊Python--Day13

智泊Python–Day13

  Day13 是面向对象的深水区，把 Day12 的「类与对象」往工程化方向推进。这一天的线索是封装的强化 → 属性的受控访问 → 方法的分类 → 继承与多态 → 特殊机制。重点掌握四个：私有属性/方法（__ 前缀做信息隐藏）、**property（把方法当属性用、还能加校验）、类方法 / 静态方法（不建对象就能调用、省内存）、以及继承 / 重写 / 多继承**（代码复用与行为定制）。最后用运算符重载和一套「学生」继承体系作业收尾。

 

1.私有属性和私有方法

  在属性 / 方法名前加 双下划线 __ 就是私有成员，只能在当前类内部访问；类外直接访问会报错。Python 的「私有」是命名改写实现的——外部其实可通过 _类名__属性 访问到，但强烈不建议，会破坏封装。公有成员则类内外都能用。

 

2.property属性

  @property 让一个方法像属性一样被读取（不用加 ()），它本质是 getter。规则：必须有返回值、不能有参数、定义在类里。搭配 @属性名.setter 还能写 setter 来赋值并做校验（比如年龄不能负数）。没有 setter 时该属性只读。

 

3.类方法和静态方法

  方法按归属分三类：

  • 对象方法（带 self）：最常见，操作对象
  • 类方法 @classmethod（带 cls）：可用 类名.方法() 直接调，不创建对象，省内存；能访问类属性 / 类方法，但访问不了对象属性
  • 静态方法 @staticmethod（无 self 也无 cls）：纯工具函数，和类 / 对象都松耦合，推荐用 类名.方法() 调用

 

4.练习

  用一个 Number 工具类把类方法 / 静态方法练熟：add_num/sub_num/mul_num/div_num 是类方法，直接操作类属性 num；add/sub 是静态方法，纯粹的二元运算。注意类方法通过 cls.num 读写类属性，静态方法不依赖任何状态。

 

5.继承

  面向对象的四大特征：封装、继承、多态、抽象。继承让子类直接获得父类的属性和方法，实现代码复用。单继承（一个父类）最常见：子类 __init__ 里用 super().__init__(...) 调父类构造来初始化共有部分，再追加自己的属性。Dog/Cat 都继承自 Animal 就是典型场景——公共的 name/age/run/sleep 提到父类。

 

6.多继承

  多继承是「一个子类继承多个父类」，把多个父类的特性合并。Python 用 MRO（方法解析顺序） 决定属性 / 方法按什么顺序查找，可用 类名.__mro__ 查看继承链。下面的 Daughter(Father, Mother) 通过 super() 链式调用分别初始化父亲给的 name 和母亲给的 sex。

 

7.重写

  重写发生在继承基础上：子类和父类有同名方法时，子类的方法会覆盖父类。这正是「多态」的体现——同样是 run()，父类返回「正在跑」、子类 Boy 返回「正在跑快」。外部调用时看对象的实际类型。

 

8.私有属性不能继承

  再强调一遍封装边界：父类的私有属性（如 __age）只在父类内部可见，子类访问不到——即使通过继承拿到了父类的方法，方法内部能用自己的 __age，但子类自己无法直接 对象.__age。非私有的 name、sex、方法都能正常继承使用。

 

9.特殊属性和运算符重载

  （本节了解即可）Python 里大量以双下划线包裹的成员叫「特殊属性 / 魔法方法」，通常由解释器自动调用。__slots__ 可限制实例能有哪些属性；__class__ / __dict__ 用于自省；__str__ / __repr__ 控制打印样式；__add__ 等则实现运算符重载——让自定义对象支持 +、直接 print 等原生语法。

 

10.作业

  综合作业：用封装 + 继承 + 重写实现「学生」体系。student 作为父类，带着 name/id/age/sex 和 learn()；Pupil（小学生）、Middle_student（中学生）、College（大学生）各自继承并**重写 learn()**，打印不同的学习内容。这个结构正是 Day12 封装与本节继承 / 多态的完整串联。
