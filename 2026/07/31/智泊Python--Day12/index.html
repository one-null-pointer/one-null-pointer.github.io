智泊Python–Day12

  Day12 进入 面向对象编程（OOP）——Python 从这一刻从「写函数」升级到「建模现实」。核心心法：类（class）是模板、对象（object）是实例；用类把「数据（属性）」和「行为（方法）」打包在一起。这一天的链条是：先对比面向过程 / 面向对象的思想差异，再定义类与对象、理解 self、搞清构造 / 析构方法，最后分清「类属性」与「对象属性」的优先级，并用四个综合作业把 OOP 真正用起来。

 

1.面向对象

  两种编程思想：

  • 面向过程：关心「先做什么、再做什么」的步骤
  • 面向对象：关心「谁来做」，用类把对象的功能封装起来

下面「小狗吃食物」用两种写法对比最直观——过程版是三个独立函数依次调用，对象版是 Dog 类把「闻 / 舔 / 咬」作为方法挂在对象上，由 dog 这个具体对象去调用。

 

2.类和对象

  类是同一类事物的抽象统称（不占内存），对象是类的具体实例（占内存，每个对象独立）。自定义类默认继承 object，__init__ 是初始化方法（构造方法），里面用 self.xxx = xxx 定义对象属性。同一个类可以 new 出任意多个对象，彼此数据互不干扰。

 

3.self详解

  self 不是 Python 关键字，只是一个约定俗成的第一个形参。你不用手动给它传值——谁调用方法，self 就指向谁。它的作用是：在方法内部通过 self.xxx 访问「当前这个对象」的其它属性和方法。理解 self 是理解面向对象的关键。

 

4.构造方法和析构方法

  两个特殊方法：**__init__ 构造方法在「创建对象时」自动调用，用来初始化；__del__ 析构方法**在「对象被销毁时」自动调用（一般不用管，了解即可）。下面 Animal('小白') 一创建就打印「被创建了」，等程序结束对象回收时打印「被销毁了」。

 

5.对象属性和类属性

  属性分两种：类属性写在类里（用 类名.属性 调用，所有对象共享），对象属性写在 __init__ 里（用 对象名.属性 调用，每个对象独立）。当对象属性和类属性同名时，通过对象访问会优先拿到「对象属性」。下面 Rerson 演示了：改类属性 Rerson.age 只影响类层面，改 p.age 只影响这个对象。

 

6.作业
