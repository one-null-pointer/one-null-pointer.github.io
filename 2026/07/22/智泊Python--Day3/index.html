智泊Python–Day3

  Day3 进入程序控制流的第一种：条件分支。Python 用 if / elif / else 表达「如果…否则…」，用 match-case（3.10+）表达「按值匹配」。和很多语言不同，Python 用缩进来界定代码块而非花括号——这是新手最容易踩的坑，也是 Python 代码统一美观的原因。

 

1.if 分支结构

  要点有四：

  • ① Python 强制缩进（通常 4 个空格），缩进深度决定语句属于哪个分支
  • ② 单分支 if、双分支 if/else、多分支 if/elif/else 依次递进
  • ③ if 可以嵌套（外层条件满足才进入内层判断）
  • ④ if 后的表达式会做隐式布尔判断，非零数字、非空容器都视为 True

  最后那个「取最大值」示例还引出了 Python 独有的三元表达式 a if 条件 else b，一行就能替代整段 if/else。

 

2.match-case 分支结构

  match-case 是 Python 3.10 起才支持的结构化模式匹配，适合「一个值与多个模式逐一比对」的场景（类似其他语言的 switch）。case "A": 匹配具体值，case _: 是通配兜底（类似 else），匹配不到任何具体分支时执行。对成绩等级这类「离散值映射」非常直观。
