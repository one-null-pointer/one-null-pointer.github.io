智泊Python–Day1

  Day1 从两块最基础的内容入手：一是程序如何与用户交互（输入 input、输出 print 的参数细节），二是 Python 的变量机制（动态类型、多重赋值、序列解包、无临时变量交换、关键字查看）。这三块是后续一切语法的地基，建议把每个例子在本地敲一遍、改几个数看看结果。

 

1.输入

  print() 默认行为是用空格连接多个参数、用换行结尾。可以通过两个参数改变它：sep 控制多个参数之间的连接符，end 控制整次输出结束后的收尾符（默认是换行 \n，也可改成制表符 \t 或不换行）。input() 永远返回字符串——就算你输入的是数字，它也是 "123" 这种字符串，要做算术必须先 int()/float() 转换类型，否则字符串相加会变成拼接而非求和。

 

2.变量

  Python 是动态类型语言：同一个变量可以先装数字、再装字符串，类型随赋值变化。a, b = 10, 20 是多重赋值，一行给多个变量同时赋值；c, *d, e = 10, 20, 30, 40, 50 里的 *d 把中间剩余的元素收集成列表（序列解包），常用于”只要头尾、中间打包”的场景；h, y = y, h 则巧妙利用”右边先打包成元组、左边再解包”实现无临时变量交换。keyword.kwlist 能打印出 Python 全部保留关键字（变量起名不能用这些词）。

 

3.作业

  三个小练习巩固「输入 + 字符串处理」：

  • ① 输入姓名，输出问候语
  • ② 用 sep 把三个字符串用加号连接输出
  • ③ 输入半径，按 π=3.14 计算圆的面积和周长

  注意第三题半径要用 float() 转换，否则无法参与小数乘法。
