智泊Python--Day7

智泊Python–Day7

  Day7 全部围绕字符串（str）展开。字符串是 Python 里最高频的数据类型，也是「不可变类型」的代表——一旦创建就不能改其中某个字符。这一天的重点是三块：

  • ① 字符串的基本操作（索引、切片、拼接、乘法、成员判断）
  • ② 字符串的常用内置方法（统计、大小写、查找、拆分/合并/替换等）
  • ③ 进阶的转义、编码解码、对齐、前后缀判断

  最后用两道作业把方法串起来实战。

 

1.字符串的基本操作

  字符串用引号包裹（单/双/三引号都行）。关键点：str 是不可变类型，所以 s[0] = "A" 会直接报错。索引和列表一致（s[0] 正序、s[-1] 倒序）；切片 s[start:stop:step] 同样适用，其中 s[::-1] 是经典的「逆序」写法。字符串之间可以用 + 拼接、* 重复，in 判断子串是否属于它。

 

2.字符串的基本功能1

  这一节是字符串方法的「主力军」。分几类记：统计类 count()；内容判断类 isupper()/islower()/isdigit()/isalpha()/isalnum()/istitle()/isspace()（这类返回 True/False，面试常考）；大小写转换 upper()/lower()/title()/swapcase()（都返回新字符串，原串不变）；类型转换 int()/float()；查找 find()/rfind()（找不到返回 -1，比 index() 更安全）；最后是拆分/合并/替换 三件套 split()/join()/replace()。

  练习部分把上面方法组合起来用。练习 1 重点是「用 find() + len() 取子串」「用切片逆序」；练习 2 重点是 split()（按分隔符拆成列表）、join()（把列表拼回字符串）、replace()（替换子串，返回新串）。

 

3.字符串的基本功能2

  进阶方法。\ 是转义字符——让本有特殊语义的字符「失效」（如 \n 换行、\\ 表示反斜杠本身）。Windows 路径里全是反斜杠，写起来很烦，所以用 r-string（r"..."）让所有转义失效，原样保留。encode() 把字符串变成字节序列（bytes），decode() 反之，是「存储/网络传输」绕不开的一步。ord()/chr() 是字符与 ASCII 码互转；strip()/lstrip()/rstrip() 去首尾空白；center/ljust/rjust 做对齐；startswith()/endswith() 判断前后缀。

 

4.作业

  两道综合题。第 1 题串起 swapcase()、isdigit()、字典计数（注意「忽略大小写」要先 lower()）和「找出最大值对应键」；第 2 题是典型的「字符串 -> 结构化列表」处理：先按 - 拆成每个学生，再按 # 拆出字段，组装成字典列表——这是解析 CSV / 接口文本的高频套路。
