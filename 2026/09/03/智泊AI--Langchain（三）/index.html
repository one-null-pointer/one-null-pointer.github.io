智泊AI--Langchain（三）

智泊AI–Langchain（三）

 

0.前言

  前面一章节通过代码了解了链的基本概念以及一些相关组件的使用，本章节主要是使用 LangChain 构建 RAG 和工具调用等操作。

 

1.RAG的基本概念

  RAG 的基本概念前面已经有介绍，这里主要是将 LangChain 作为了中间层进行更好的调用与编排。

 

2.文档加载的实现

  在日常需求中，我们处理的知识文档存在很多种类型，比如文本文件、Word 文档、Excel 表格、PDF 文件等。而 LangChain 提供了很强的数据加载能力，从而支持多种插件的数据格式，例如：

  • TXT文档:TextLoader
  • CSV文档:CSVLoader
  • PDF文档:PyPDFLoader
  • JSON文档:JSONLoader
  • HTML文档:UnstructuredHTMLLoader
  • MD文档:UnStructuredMarkdownLoader
  • 文件目录:DirectoryLoader

  加载器有 load 方法，用于从指定的数据源读取数据，将其转换成一个或多个文档。

 

3.文档切割

  LangChain 也提供了很多现成的分割器：

  • CharacterTextSplitter

  chunk_overlap 表示文本块之间的最大重叠。基于字符（默认以 “\n\n” 为分隔）进行切割，并通过字符数量来测量文本块大小：chunk_size 控制文本块大小，chunk_overlap 控制文本块之间的最大重叠。

  • RecursiveCharacterTextSplitter

  在前面我们已经了解过，除了自然语言，它也支持对特定的编程语言（JavaScript、cpp、go、java、php、python 等等）的代码进行切割。

  • MarkdownHeaderTextSplitter

  可以根据指定的一组标题来切割一个 Markdown 文档。

  • 官方内置分割器地址：

https://reference.langchain.com/python/langchain-text-splitters

  LangChain 的文档转换器处理任务中将动作分为了两步，第一步是对文档进行了切割，主要由切割器完成，第二步是将切割后的文档转化为了 Document 对象/数据格式。

  LangChain 中的数据以 Document 对象和向量的形式在各个包装器中流通，该对象包含了文本以及相关元数据，是 LangChain 在 RAG 处理中非常重要的一个概念。

 

4.嵌入模型包装器

  LangChain 框架提供了一个 Embeddings 的类，为多种文本嵌入模型提供了统一的接口，可以通过文档转换为向量数据，同时将搜索的问题也转换为向量数据。

  实例化的 Embeddings 类则被称为嵌入模型包装器。

 

5.检索器

  检索器是 RAG 系统的核心组件，负责从知识库中查找与用户查询相关的文档片段，返回的对象是 VectorStoreRetriever，除了所展示的四个检索器外还有其他高级的检索器，后续 RAG 深入的时候会提到。

  其中的 as_retriever() 则代表了向量检索，在检索器中，主要分为了三种模式：

  similarity：按照相关性取的前 k 个向量，默认 k=4。

  similarity_score_threshold：设置了相关性阈值，只取高于该阈值的向量。

  mmr：平衡相关性与多样性，主要应用场景：1.摘要任务 2.问答系统 3.推荐系统。

6.create_retrieval_chain

  前面第二节中，我们提到了 create_retrieval_chain 是用于构建 stuff 文件链的核心函数，这种链的作用是将所有的相关文档直接整合到提示词中，传递给大模型(LLM)生成回答，适用于文档量较小的情况。

  而 create_retrieval_chain 是 LangChain 框架中用于构建检索增强生成系统的核心函数，将文档检索器和文档处理链组合成一个完整的问答流程。

 

7.工具调用

  大模型需要使用工具的前提是必须找到各种工具的使用说明，当遇到具体场景，能够从工具库中选择合适的工具使用。

7.1 自定义工具

  在 LangChain 语法中使用 @tool 定义工具，同时需要加入文本的描述，让大模型理解工具的作用，需要注意的是工具函数的描述一定要在第一行。

  也可以通过 Tool 自定义方法。

7.2 大模型的简单调用

  model.bind_tools([get_date, open_browser]) 使用列表的方式传入，bind_tools 绑定相关工具。

7.3 agent形式的调用

  agent 的调用在 Langchain 中使用 create_agent 进行包装，在 tools 中填入工具。
